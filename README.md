This is my Week 5 lab activity where I worked on basic Python programming concepts and
small programs to practice what I learned. In this week, I focused on understanding
functions, loops, conditional statements, and how to handle user input to create simple
programs that perform specific tasks.

function, pass arguments to it, and return values. I also practiced calling functions from

for and while, to repeat tasks like processing multiple inputs or iterating over a range
of numbers. I learned how to use conditional statements like if, elif, and else to
make decisions in the program based on user input or calculated values.

One of the main tasks in this week was creating small programs where I asked the user for
input, processed the input using calculations or logic, and then displayed results. I used
variables to store data and learned the importance of naming them clearly to make the
code easy to read. I also included input validation in some programs to handle unexpected
or incorrect inputs so the program would not crash.

This lab activity helped me practice combining different Python concepts together. I
learned how to break a problem into smaller tasks, write functions to solve each task, and

expected.

This week gave me more confidence in writing Python programs and preparing for more
